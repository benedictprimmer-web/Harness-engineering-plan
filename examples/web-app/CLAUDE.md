# Acme Fleet Dashboard

## Project

A customer-facing Next.js 14 web application for enterprise operations teams to monitor and configure IoT sensor networks in real time. Frontend-only — the backend API lives in a separate `api-service/` repository. This dashboard connects to that API and a WebSocket feed for live sensor data.

## Stack

- **Runtime**: Node 20, pnpm 9.4
- **Framework**: Next.js 14.2 (App Router)
- **UI**: Tailwind CSS 3.4, shadcn/ui, Radix UI primitives
- **State**: Zustand 4 (client state), React Query 5 (server state)
- **Maps**: Mapbox GL JS 3
- **Testing**: Vitest 1.x + React Testing Library
- **Linting**: ESLint (flat config `eslint.config.mjs`), Prettier 3
- **Type checking**: TypeScript 5.4 (strict mode)

## Commands

```bash
pnpm install              # install dependencies
pnpm dev                  # dev server on :3000 (with Turbopack)
pnpm build                # production build
pnpm start                # serve production build locally
pnpm test                 # run all tests (vitest)
pnpm test:watch           # tests in watch mode
pnpm lint                 # eslint + tsc --noEmit
pnpm lint:fix             # auto-fix eslint issues
pnpm storybook            # component explorer on :6006
pnpm generate:api         # regenerate API client from OpenAPI spec
```

## Architecture

```
app/                      ← Next.js App Router
  (auth)/                 ← unauthenticated routes (login, signup)
  (dashboard)/            ← authenticated routes (route group, no URL segment)
    layout.tsx            ← dashboard shell (sidebar, nav)
    devices/              ← device list + detail pages
    alerts/               ← alert management
    settings/             ← org settings
components/
  ui/                     ← shadcn/ui primitives (DO NOT edit — re-generated by shadcn CLI)
  features/               ← product components (devices, alerts, maps)
  layouts/                ← page layout components
lib/
  api/                    ← AUTO-GENERATED API client (run pnpm generate:api after API changes)
  stores/                 ← Zustand stores (one file per domain)
  hooks/                  ← shared React hooks
  utils/                  ← pure utility functions
public/
  icons/                  ← SVG icons (from Figma export, don't edit manually)
```

## Conventions

- **Imports**: use `@/` alias for the project root (not relative `../../../`)
- **Components**: named exports only, no default exports, one component per file
- **Styling**: Tailwind classes only — no inline styles, no CSS modules, no styled-components
- **Server state**: use React Query for all async data — never `useEffect` for fetching
- **Client state**: use Zustand stores — no Context API for app state
- **API calls**: always go through `lib/api/` generated client — never raw `fetch`
- **Forms**: `react-hook-form` + `zod` schema for validation
- **Dates**: `date-fns` for all date manipulation (never `new Date()` arithmetic)
- **Icons**: `lucide-react` only — don't add other icon libraries

## Environment

Copy `.env.example` to `.env.local` and fill in:
- `NEXT_PUBLIC_API_URL` — backend API base URL (use `http://localhost:8000` locally)
- `NEXT_PUBLIC_WS_URL` — WebSocket URL (use `ws://localhost:8000/ws` locally)
- `NEXT_PUBLIC_MAPBOX_TOKEN` — get from 1Password → "Mapbox Dev Tokens"
- `NEXT_PUBLIC_SENTRY_DSN` — optional for local dev, required for staging/prod

## Gotchas

- **pnpm only**: never run `npm install` or `yarn` — it creates a conflicting lockfile. If you see `package-lock.json`, delete it.
- **`lib/api/` is auto-generated**: never edit files in `lib/api/` by hand — they're overwritten by `pnpm generate:api`. If you see type errors there, add a `// @ts-ignore` with a note.
- **`components/ui/` is managed by shadcn CLI**: don't edit these files. To add a new shadcn component: `pnpm dlx shadcn@latest add <component>`.
- **App Router vs Pages Router**: this project uses App Router only. If you see examples from Pages Router docs (`getServerSideProps`, `_app.tsx`), they don't apply here.
- **Turbopack in dev**: `pnpm dev` uses Turbopack. If you hit a Turbopack bug, fall back with `pnpm dev --no-turbo`.
- **Mapbox requires HTTPS**: the map won't load on HTTP except localhost. Don't test map features on HTTP staging.
- **React Query devtools**: available in dev by pressing the React Query logo button in the corner — useful for inspecting cache state.
