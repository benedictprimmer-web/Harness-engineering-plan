# Patterns

## Task Packet

A good task packet contains:

- Purpose
- Relevant files
- Editable paths
- Non-editable paths
- Acceptance criteria
- Verification commands
- Context budget
- Trace summary requirement

## Health Audit

The audit scores six dimensions:

- Task clarity
- Context discipline
- Traceability
- Branch freshness
- Test coverage
- Safety

## Finding Categories

- `missing_context`
- `over_broad_context`
- `stale_branch_state`
- `repeated_check_failure`
- `unclear_task_acceptance`
- `missing_editable_paths`
- `missing_trace_summary`
- `unsafe_high_impact_task`
- `weak_or_untested_prompt_rule`
