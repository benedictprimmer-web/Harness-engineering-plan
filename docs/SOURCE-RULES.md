# Source Rules

## V1 Sources

Use local project files, run logs, task boards, handoff notes, and explicit user-provided references.

## Social And External Intake

Live Reddit, X, marketplace, forum, or competitor ingestion is excluded from v1. Add it only after credentials, API terms, retention rules, and source attribution policy are approved.

## Evidence Standard

When the harness creates an improvement task, it should cite the local file signal or audit finding that triggered it.
